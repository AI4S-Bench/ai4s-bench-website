Process

How a task enters AI4S-Benchmark

Every task travels the same transparent path from proposal to versioned release — with GitHub as the canonical record at each step.

  1. 01

    Submit

    A researcher proposes a task through the proposal form.

  2. 02

    Scientific Review

    Automated checks verify format and duplication; domain reviewers assess scientific value.

  3. 03

    Task PR

    Specification, environment, evaluator and anti-cheating measures land as a structured pull request.

  4. 04

    Agent Testing

    Frontier agents are run; pass rate, runtime, cost and failure modes are recorded.

  5. 05

    Release

    Verified tasks enter a versioned AI4S-Benchmark release.

Editorial

Why interdisciplinary science?

Many of the most important scientific questions live where fields meet — and that is exactly where evaluation is hardest to find. AI systems can combine information across disciplines unusually well: knowledge, reasoning, code, tools and domain judgment in a single loop.

Interdisciplinary tasks may therefore be especially valuable for measuring emerging scientific capability — the kind that does not show up in single-domain question answering.
