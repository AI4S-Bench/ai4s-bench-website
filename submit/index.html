Before you submit

Three bars every task must clear

01

Scientific value

Would researchers in the field consider this problem worth solving? Avoid tasks whose difficulty was invented purely to confuse an AI.

02

Verifiable

Can success be determined through a programmatic evaluator, clearly defined metric or rigorous scientific verification procedure?

03

Genuinely challenging

The task should remain difficult for frontier agents — or involve a workflow whose solution itself constitutes meaningful scientific work.

Interdisciplinary tasks are especially encouraged.
